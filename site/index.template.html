装进项目，只要两步

安装包，把表情资源复制到 public 目录。然后按名字取路径，类型会替你检查拼写。

npm 页面 ↗

第一步 · 安装

终端 
npm install wechat-emojis

第二步 · 复制资源

终端 
mkdir -p public/assets
cp -r node_modules/wechat-emojis/assets/* public/assets/

按名字、分类或关键词取用

所有函数都带类型，EmojiName 会拦住不存在的名字。

TypeScript 
import {
  EmojiCategory,
  getEmojiPath,
  getEmojisByCategory,
  searchEmojis,
} from 'wechat-emojis';

const path = getEmojiPath('旺柴');
// 'assets/face/旺柴.png'

const faces = getEmojisByCategory(EmojiCategory.FACE);
// {{FACE_COUNT}} 个

const laugh = searchEmojis('笑');
// 微笑、偷笑、坏笑……

在 React 里铺一面表情墙

getEmojisByCategory 返回的每一项都带有 path，直接作为图片地址即可。

React + TypeScript 
import {
  EmojiCategory,
  getEmojisByCategory,
} from 'wechat-emojis';

export function EmojiPicker() {
  return (
    <div className="emoji-grid">
      {getEmojisByCategory(EmojiCategory.FACE).map((emoji) => (
        <img
          key={emoji.name}
          src={emoji.path}
          alt={emoji.name}
          width={48}
          height={48}
        />
      ))}
    </div>
  );
}
