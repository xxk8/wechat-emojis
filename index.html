装进项目，一行就够

安装之后用 getEmojiUrl 直接拿图片地址，不用复制任何文件。想自托管时再复制 assets。

npm 页面 ↗

第一步 · 安装

终端 
npm install wechat-emojis

第二步 · 直接用

TypeScript 
import { getEmojiUrl } from 'wechat-emojis';

<img src={getEmojiUrl('旺柴')!} alt="旺柴" />

按名字、分类或关键词取用

所有函数都带类型，EmojiName 会拦住不存在的名字。

TypeScript 
import {
  EmojiCategory,
  getEmojiUrl,
  getEmojisByCategory,
  searchEmojis,
} from 'wechat-emojis';

const url = getEmojiUrl('旺柴');
// 'https://cdn.jsdelivr.net/npm/wechat-emojis@2/assets/face/旺柴.png'

const faces = getEmojisByCategory(EmojiCategory.FACE);
// 75 个

const laugh = searchEmojis('笑');
// 微笑、偷笑、坏笑……

在 React 里铺一面表情墙

getEmojisByCategory 返回的每一项都带有 path，直接作为图片地址即可。

React + TypeScript 
import {
  EmojiCategory,
  getEmojisByCategory,
} from 'wechat-emojis';

export function EmojiPicker() {
  return (
    <div className="emoji-grid">
      {getEmojisByCategory(EmojiCategory.FACE).map((emoji) => (
        <img
          key={emoji.name}
          src={emoji.path}
          alt={emoji.name}
          width={48}
          height={48}
        />
      ))}
    </div>
  );
}

API 速查

完整签名见仓库里的 docs/API.md。

wechat-emojis 2.1.0 的公开函数
函数 返回 说明
getEmojiPath(name)string | null取包内相对路径（自托管时用）
getEmojiUrl(name)string | null取可直接渲染的图片 URL
getEmojiInfo(name)EmojiInfo | null取名称、分类和路径
getEmojisByCategory(category)EmojiInfo[]按分类取列表
getAllEmojis()EmojiInfo[]取全部 109 个
searchEmojis(keyword)EmojiInfo[]按名称子串搜索
hasEmoji(name)boolean检查名字是否存在
getEmojiNames(category?)string[]取名称列表
getRandomEmoji(category?)EmojiInfo随机取一个
